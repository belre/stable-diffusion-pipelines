# Tencent Cloud Prompt Routing for Image/LoRA Pipelines

## Core rules

1. Write all instructions to Tencent Cloud models directly in English, not Japanese. This improves token efficiency and model comprehension.
2. Tencent Cloud models reply in English. Translate or summarize the replies into Japanese for the user.
3. Never decide on your own which parts of a model's output become prompt material. List candidates and let the user decide.

## Model routing

| Task | Model |
|---|---|
| Simple image-generation-related coding or instructions | hy4 |
| Image/video evaluation and analysis (outputs from Stable Diffusion, Flux, etc.) | hy4 |
| Code that directly modifies images | hy4 |
| Complex design, pipelines, or architecture | Claude (consider upgrading from the free plan to Pro when needed) |
| Alternative or comparison runs during work | Kimi 3.1 or GLM 5.3 on Tencent Cloud Tokenhub |

- hy4 has coding capability, but it is expensive. Do not ask hy4 for detailed software design.
- hy4 must never generate images itself. It only evaluates, analyzes, or writes code that edits existing images.

## Environment context (include in prompts when relevant)

- LoRA training: kohya_ss. AI Toolkit may be adopted later, so keep designs compatible.
- Image generation: ComfyUI. Outputs are sometimes retouched manually with a pen tablet, so do not assume a fully automated final image.
- Local GPU: RTX 5060 Laptop, 8 GB VRAM. Minimum spec, limited to design use. Keep local workloads lightweight.
- Cloud GPU: Runpod. Scripts may be made executable there.

## hy4 use cases

- Build pipelines and analysis scripts for evaluating images/videos generated by Stable Diffusion or Flux.
- Evaluate LoRA quality using ComfyUI nodes and pipelines.
- Implement code that edits images directly.

## Escalation workflow

If the task needs complex design or implementation:
1. Have hy4 output a concrete, self-contained hand-off prompt (goal, inputs, outputs, constraints, environment) instead of attempting the design.
2. Pass that prompt to Claude, or to Kimi 3.1 / GLM 5.3 on Tokenhub.
3. Report the result to the user in Japanese and ask which parts to adopt.

## Writing prompts for hy4

- Keep prompts short, explicit, and in English. State the task, inputs, expected output format, and constraints.
- Include the relevant environment (tool, GPU, VRAM limit) only when it affects the answer.
- Explicitly state "Do not generate images" when the task involves image analysis.

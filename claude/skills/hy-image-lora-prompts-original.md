

## Anthropic Skill to generate prompts to tencent cloud hy4 for stable diffusion

- Tencent Cloudへの指示を日本語から英語に変換する。
  - 画像生成に関する簡易なコーディングや指示で使うモデル: hy4
  - コーディングやパイプラインに関しては複雑な設計が伴う場合は
    claudeでコーディングすることも考慮してよい。
    - 現状はfree版で運用しているので、その用途であれば必要に応じてproに課金する。
    - その他、Tencent Cloud Tokenhubのkimi3.1 or GLM5.3辺りも作業の過程で試すことは考慮してよい。
    - hy4にもコーディング機能があるが、コストが高いため詳細な設計はさせないようにする。
  - トークン効率や理解効率を上げた指示を出すために、英語で直接指示を出す。
  - 出てきた結果は英語で返ってくるので、翻訳などでAnthropicに相談する。
    ただし、どの内容を抽出してプロンプト材料の判断材料としては人が決める。

- hy4へはStable DiffusionやFluxなどで生成された画像・動画などを評価するためのパイプラインや解析に使用する。
  - LoRA学習用途で使用する：kohya_ss
    - AI Toolkitを将来使う可能性はあるので考慮に入れる
  - 生成用途で使用する：ComfyUI
    - ComfyUIで生成された画像は状況に応じて、手動でペンタブで修正することがある。
  - GPU
    - ローカル環境: RTX 5060 laptop VRAM 8GB (最低限であり、デザイン用途に限定する)
    - クラウド環境: Runpodで展開する. スクリプト実行可能にしてもよい。
  - hy4では、画像自体の評価・解析及び画像の直接修正が必要なコードの実装（hy4自体が画像生成はしないようにする）
    ComfyUIノードやパイプラインを活用したLoRAの評価を実施する。
  - 複雑な設計や実装が必要になった場合、hy4からClaudeや他モデル（Tencent Cloud Tokenhub上のKimi 3.1, GLM 5.3など）へ渡すための具体的な指示文（プロンプト）を出力させる。
